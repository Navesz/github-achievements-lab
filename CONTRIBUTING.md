# Como contribuir

Obrigado por colaborar com o GitHub Achievements Lab.

## Perguntas

Use a aba Discussions para perguntas sobre GitHub, Git, pull requests,
coautoria ou automação. Descreva o contexto, o resultado esperado e o que você
já tentou. Quando uma resposta resolver a pergunta, marque-a como aceita.

## Alterações no repositório

1. Abra uma issue explicando a melhoria ou o problema.
2. Crie uma branch curta e focada.
3. Faça commits descritivos.
4. Abra um pull request que explique como a mudança foi validada.
5. Use coautoria somente quando outra pessoa tiver contribuído de verdade.

Não envie mudanças vazias ou repetitivas apenas para aumentar contadores.
